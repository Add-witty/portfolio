Real-Time Sign Language Interpreter

A lightweight, browser-based sign language translation system that converts hand gestures into text and speech in real time using only a standard webcam. By operating on MediaPipe skeletal landmarks instead of raw images, it achieves high accuracy with minimal compute no installation or specialised hardware required.

Achieved over 90% gesture classification accuracy with inference latency under 200ms.
WebSocket server handles real-time bidirectional communication between browser and backend, supporting concurrent users without degradation.
Integrated text-to-speech output and a sentence-building mechanism for stable, meaningful communication.
Runs entirely CPU-only in the browser no specialised hardware needed, maximising accessibility.
Python MediaPipe Dense Neural Network WebSockets React
03
Computer Vision / Deep Learning Research

Deep Learning-Based Change Detection using Remote Sensing

A transformer-based change detection system that identifies land-use changes between two satellite images taken months or years apart. Built on the BIT (Bitemporal Image Transformer) architecture, the model processes pairs of temporal remote sensing images and outputs pixel-level change masks useful for environmental monitoring, urban expansion tracking, and disaster assessment.

Achieved 96.53% accuracy with an F1 Score of 0.6842 and IoU of 0.5199 on remote sensing benchmark data.
Implemented the full BIT architecture from scratch, handling bitemporal image pairs end-to-end.
Evaluated rigorously across Accuracy, Precision (0.6380), Recall (0.7375), F1, and IoU metrics.
Applied transformer attention mechanisms to capture long-range spatial dependencies across temporal image pairs.
Python TensorFlow BIT NumPy Matplotlib
04
NLP / Multi-Task Learning

Automotive Defect Detection in Production Reports

An Intelligent Defect Management System (IDMS) that analyses free-text production reports to simultaneously classify defect category and severity level using a multi-task BERT model. The system also recommends the most suitable supervisor for resolution by analysing past efficiency data, and generates concise report summaries via TextBlob replacing slow, error-prone manual inspection workflows.

Multi-task BERT model predicts defect category and severity simultaneously from a single textual input, reducing pipeline complexity.
Supervisor recommendation engine analyses historical resolution efficiency to route issues to the most effective handler.
TextBlob integration auto-summarises verbose defect reports, cutting review time for engineers.
Addresses a direct industry pain point in manufacturing QA moving from reactive manual inspection to proactive AI-assisted triage.
Python PyTorch BERT TextBlob Multi-Task Learning
